How to use:

1. Run the installer on the host laptop.
2. Allow firewall access for TCP port 5173.
3. Copy the Event URL shown by the app on the host laptop.
4. On every other laptop, open that Event URL. Do not use localhost on client laptops.
5. Pick the correct role from the start page.

Client laptops can use automatic IP addresses.
No password is required on the event LAN.
