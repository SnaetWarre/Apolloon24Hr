# Rehearse on the event laptops

Use a scratch race and the same native release on each laptop.

1. Connect the laptops to the event switch. Import a small registration list on the first laptop. Check that the other laptops find it by name and that the list appears on each after pairing.
2. On the second monitor, move the browser window to the public screen and press F11. Start timing and confirm a handoff appears there.
3. Unplug one laptop while the other two are connected. Check that the surviving group saves laps. Reconnect the laptop, wait until Beheer shows that it caught up, and compare the lap totals.
4. Download the latest backup. Open a copy in a disposable profile and verify the runners and laps. Use the event checklist in [recovery](reliability-model.md) before replacing the scratch data with the real registrations.
